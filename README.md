# 音節小勇士 Syllable Hero

給 ADHD 孩子的英文複習 PWA。內容取自課本 **Get Ready、Unit 1 The Birthday Party、Unit 2 Poor Kevin、Review 1（p.5–22）**。

## 怎麼記單字

每個單字都拆成彩色的「音節積木」：

- 多音節字按音節拆：`hap · py`、`sev · en`、`ig · loo`
- 課本裡的短單字拆成「字首音 + 韻尾」：`h · en`、`b · ig`、`d · ad`（對應課本的 `_ig` / `_en` 練習）

點一塊積木就念那一塊的音，「🐢 一拍一拍」會一塊一塊念完，再念整個字。

## 三種模式

| 模式 | 內容 |
| --- | --- |
| 🔍 預習 | 認識新字（自動一拍一拍念）→ 👏 拍鼓數拍數 → 🧩 拼積木 → 🗣️ 排句子 |
| 🔁 複習 | 聽音選字、看中文選英文、缺哪一塊、開頭字母、拼積木、一拍一拍拼字、排句子。用間隔重複（Leitner 盒子）挑該複習的字；答錯的字會在同一回合最後再練一次 |
| ⚔️ 考試打怪 | 最多 10 個字加上 2 句句子，題型混合（拼字比重最高），選項不顯示音節顏色提示。每答對一題就打怪獸一下，最後拿 1–3 顆星 |

## 遊戲元素（照顧 ADHD 孩子的設計）

- 每回合只有 3–8 個字（預設 4 個），每個畫面只做一件事，按鈕都很大
- 答對馬上有音效、星星和連擊；答錯不扣分，會直接示範正確答案
- 寵物會隨等級長大：🥚→🐣→🐥→🦖→🐲→🐉。另外有連續天數 🔥、每日任務寶箱 🎁 和貼紙本 🏅
- 每回合結束有 20 秒「動一動」腦袋休息
- 家長設定裡有安靜模式（減少動畫）、音效開關和念讀速度

## 改單字

- 直接編輯 `words.js`，或在 App 裡進 ⚙️ 家長（要答一題乘法）→「課本單字表」
- 格式：`hap-py | 快樂的 | 😄 | I'm happy.`。用 `-` 分音節，用 `+` 分字首音（例如 `h+en`）。以 `>` 開頭的是句子，以 `#` 開頭的是單元名稱

## 執行與安裝

純靜態網頁，沒有任何相依套件和 build。放到任何 HTTPS 靜態主機上（GitHub Pages、Netlify 或 nginx 都可以），或在本機執行：

```
cd english-review-pwa && python3 -m http.server 8000
```

- 手機安裝：iPhone 用 Safari →「分享」→「加入主畫面」；Android 用 Chrome →「安裝應用程式」
- 安裝後可以離線使用
- 學習紀錄只存在這台裝置的瀏覽器裡（localStorage），不同裝置之間不會同步
- 發音用的是瀏覽器內建的語音合成（英文語音）。單一子音會念成音（h → "huh"），但像 `ig`、`od` 這種很短的韻尾，有些裝置的語音可能念得不太自然
